# Prompt engineering aplicado al desarrollo

En este documento se recopilan prompts utilizados durante el desarrollo del proyecto TaskFlow utilizando herramientas de inteligencia artificial.

Se probaron diferentes técnicas de prompting para generación de código, refactorización, explicación de conceptos y documentación.

---

# Técnicas utilizadas

## Roles

Se utilizaron prompts donde la IA asumía un rol específico, como desarrollador senior o profesor.

## Few-shot prompting

Se utilizaron ejemplos previos para orientar mejor las respuestas.

## Razonamiento paso a paso

Se pidió a la IA explicar procesos de forma secuencial para entender mejor el código.

## Restricciones claras

Se utilizaron instrucciones específicas para controlar el tipo de respuesta generada.
