# Experimentos con IA en programación

En este documento se registrarán experimentos comparando la resolución de problemas de programación con y sin ayuda de inteligencia artificial.

Se analizará el tiempo invertido, la calidad del código y el nivel de comprensión obtenido en cada caso.

# Refactorización con IA

Se utilizaron herramientas de inteligencia artificial para mejorar la estructura del proyecto TaskFlow.

## Mejoras realizadas

- Se añadieron validaciones adicionales al formulario
- Se mejoraron nombres de variables para hacer el código más legible
- Se añadieron comentarios JSDoc
- Se simplificaron funciones repetitivas

## Resultado

La IA ayudó a identificar partes del código que podían organizarse mejor y permitió hacer el proyecto más limpio y mantenible.
