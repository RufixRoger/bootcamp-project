# Diseño de TaskFlow

La aplicación tendrá las siguientes secciones:

- Cabecera con el título "TaskFlow"
- Formulario para añadir tareas
- Lista de tareas
- Panel de estadísticas con:
  - Total de tareas
  - Tareas completadas
  - Tareas pendientes

También incluirá:
- Filtros (todas, pendientes, completadas)
- Búsqueda de tareas
- Botones para editar y eliminar tareas
